Title:🎓 Online Course Completion Prediction System

📌 Project Overview

The Online Course Completion Prediction System is a Machine Learning and Data Analytics project developed to predict whether a learner is likely to:
✅ Complete the course
⏳ Remain In Progress
❌ Drop the course

The project also includes an interactive Power BI Dashboard that provides meaningful insights about student behavior, learning platforms, course popularity, completion trends, and learner performance.
